# Noircess Website

## Overview

The **Noircess Website** is the official corporate website for **Noircess**, a technology and digital services company focused on building modern digital solutions for businesses and individuals.

The website serves as Noircess's digital presence, providing information about the company, its services, solutions, projects, and ways for potential clients to get in touch.

The project is designed with a clean, modern, responsive interface using Noircess's core brand identity of **black, blue, and white**.

---

## Getting Started

### Prerequisites

To work on the project locally, you need:

* A computer
* Git
* Visual Studio Code or another code editor
* A modern web browser
* GitHub account for repository access

---

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/noircess-website.git
```

### 2. Enter the project directory

```bash
cd noircess-website
```

### 3. Open the project in VS Code

```bash
code .
```

### 4. Run the website

Because the website is currently a front-end project, you can open:

```text
index.html
```

directly in your browser.

For a better development experience, you can also use the **Live Server** extension in VS Code.

3. Test the changes locally.
4. Save the files.
5. Check the website in a browser.
6. Review the changes with Git.
7. Commit the changes.
8. Push the changes to GitHub.

Example:

```bash
git status
```


```bash
git commit -m "Update website content"
```
